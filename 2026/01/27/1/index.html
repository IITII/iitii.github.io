群辉迁移 pve9: 恢复 Windows 篇

发表于 2026-01-27 更新于 2026-02-27 分类于 群辉 ， pve ， windows ， 飞牛 阅读次数： Valine：
本文字数： 556 阅读时长 ≈ 1 分钟
将群辉 VMM 虚拟机 VMDK 文件导出到 PVE

Windows 之前是在 群辉的 VMM 中运行, 单个 VMDK 文件.

准备工作

  1. Win10 镜像, msdn itellyou 自行下载
  2. VirtIO 驱动, https://fedorapeople.org/groups/virt/virtio-win/direct-downloads/stable-virtio/virtio-win.iso
  3. ISO 上传到 PVE

创建虚拟机

没提的就默认

  1. 常规 → 默认
  2. 操作系统
    1. ISO 镜像 → Windows
    2. 客户机操作系统 → Windows
    3. 为 VirtIO 添加额外的驱动程序 → 选择上面下载的 VirtIO 驱动
  3. 系统
    1. 机型 → q35
    2. BIOS → UEFI
    3. 添加 EFI 磁盘 → local
    4. 添加 TPM 磁盘 → local
    5. → 机型 q35
  4. 磁盘, 50G 够用
  5. CPU → 类别 host
  6. 内存 → 4G
  7. 创建完成
  8. 虚拟机 → 选项 → 引导顺序: Windows 镜像, VirtIO 驱动镜像
  9. 启动安装完成

将 VMDK 导入到虚拟机

假设虚拟机 VM ID 为 200

  1. 将 vmdk 上传到 pve root 目录(其他目录也可
  1. 虚拟机 → 硬件 → 硬盘 → 未使用的硬盘 → 双击 → 总线 (必须选 IDE) → OK
  2. 重启后, 在我的电脑应该就能看到对应磁盘
